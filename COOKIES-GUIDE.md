# How to Get Your Instagram Cookie Information

This guide explains how to obtain the Instagram session cookies used by the
IG Feed Watcher (`watcher.js`) and the Posting API (`post-server.js`), how to
store them, when to refresh them, and how to stay safe with them.

> Generated by `./get-ig-cookies.sh` — run that wizard again whenever your
> session expires; it walks you through this process interactively and writes
> the cookies into `sources.json` for you.

## What you need and why

| Cookie | What it is | Sensitivity |
| --- | --- | --- |
| `sessionid` | Your login session token — the credential that proves you are you. | 🔴 Treat as a password: full account access. |
| `ds_user_id` | Your numeric Instagram user ID. | 🟡 Private-ish; identifies your account. |
| `csrftoken` | CSRF token paired with the session, sent with every request. | 🟡 Sensitive; rotates with the session. |
| `mid`, `ig_did`, `rur` | Device / region cookies; optional but Instagram may ask for them. | 🟢 Low sensitivity. |

`sessionid` alone is enough to take over an account: anyone holding it can read
your DMs, post as you, and change your password. Keep it out of chats, issues,
commits, and screenshots.

## Where the cookies live in this repo

- `sources.json` → source `ig-primary` ("Primary Instagram") — the **active**
  config. One entry per account, each with its own `cookies` array.
- `cookies.json` — the **legacy single-account** fallback, used only when
  `sources.json` is absent.
- Both files are listed in `.gitignore` and must never be committed.

Cookie entry format (Puppeteer / DevTools shape):

```json
{
  "name": "sessionid",
  "value": "YOUR_SESSION_ID",
  "domain": ".instagram.com",
  "path": "/",
  "secure": true,
  "httpOnly": true,
  "sameSite": "Lax"
}
```

## The manual way (step by step)

1. Open `https://www.instagram.com/` in your desktop browser and **log in**.
2. Press `F12` to open DevTools.
3. Chrome / Edge: open the **Application** tab. Firefox: open the **Storage** tab.
4. In the left sidebar expand **Cookies** and click `https://www.instagram.com`.
5. Use the **Filter** box to find each cookie by name.
6. For each cookie below, click the row and copy the **Value** cell:

| Order | Cookie | Looks like |
| --- | --- | --- |
| 1 | `sessionid` | long alphanumeric token (~30+ chars) |
| 2 | `ds_user_id` | a number (your user ID) |
| 3 | `csrftoken` | 32 hex-like characters |

7. Paste the values where they belong:
   - into the wizard (`./get-ig-cookies.sh`), or
   - into the Web Explorer settings page (🔑 Sources), or
   - by hand into `sources.json` / `cookies.json` (format above).

## Verify the cookies work

```bash
node watcher.js
# posting API status:
node post-server.js   # then: curl -s http://localhost:4030/status
```

`GET /api/sources` (server.js, port 4180) lists cookie names per source with
values masked — a safe way to confirm which cookies are configured.

## Refresh when the session expires

Instagram rotates sessions — expect to re-export every few weeks. Symptoms:

- the watcher logs `login required`, `challenge`, or 401 responses;
- the feed comes back empty or redirects to the login page;
- posting fails with a login / challenge error.

Fix: re-run `./get-ig-cookies.sh`. The wizard keeps other cookies (e.g. `mid`,
`ig_did`) and only replaces `sessionid`, `ds_user_id`, `csrftoken`.

| Method | Command | Needs |
| --- | --- | --- |
| Chrome profile export | `python3 export-cookies.py` | Local Chrome profile on this machine |
| Interactive login helper | `node login.js` | A display / X11 (not headless) |
| Browser extension | e.g. "Get cookies.txt LOCALLY" | Paste the exported lines into the same format |

## Security rules

- `sessionid` is a full login credential — never paste it into chat, issues,
  commits, or screenshots.
- `sources.json` and `cookies.json` are gitignored; if they were ever
  committed, rotate your password and remove them from git history.
- Cookies are tied to the browser/login they came from; using an export on
  another device usually works, but Instagram may flag the device/IP change.
- This project automates a real browser with your real session. Instagram can
  detect automation — use at your own risk and keep polling gentle (5–15 min).
